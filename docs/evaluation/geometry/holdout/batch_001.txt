# ─── LUẬT NHẬN BÀI ─────────────────────────────────────────────────────
#
#   NHẬN : đề TỰ LUẬN · yêu cầu dựng hình hoặc tính · ĐẶT ĐƯỢC VÀO TOẠ ĐỘ HỮU TỈ
#   LOẠI : trắc nghiệm 4 phương án · chọn đáp án
#          dữ kiện hoặc đáp án CÓ CĂN (a√3, a√2/2 …)   ← rất phổ biến, coi kỹ
#          đề tham chiếu "hình vẽ bên" mà văn bản không có
#          mặt cầu · nón · trụ (kernel dựng trên đa diện)
#          Oxyz cho sẵn toạ độ (mô hình phải TỰ đặt hệ trục — đó là nửa khó)
#
# ⚠️ LUẬT ĐỦ, và là luật DUY NHẤT đủ: "đặt được cả hình vào toạ độ HỮU TỈ
#    không?" Ba hình sau KHÔNG, dù đề và đáp án trông sạch:
#      · tam giác vuông CÂN        (1 : 1 : √2)
#      · tam giác ĐỀU              (đường cao a√3/2)
#      · góc 30° · 60° · 120°      (tan/cos sinh √3)
#    GIỮ: tam giác vuông có hai cạnh góc vuông là BỘI NGUYÊN của a.
#
# ─── ĐƠN VỊ `ĐÁP ÁN` (dẫn từ `geometry_exec._do`) ──────────────────────
#
#   thể tích      phân số:  4   ·   4/3          ← KHÔNG viết 1.333
#   khoảng cách   phân số, và phải HỮU TỈ         ← có căn ⇒ LOẠI bài
#   góc đ–đ, m–m  cos²   ·  góc đ–MẶT  →  sin²    ← khác nhau, coi kỹ
#   quan hệ       true  /  false
#
# ⚠️ SÁCH VIẾT ĐÁP ÁN THEO `a`, Ở ĐÂY PHẢI GÁN `a = 1`:
#
#     sách:  V = 2a³/3        →  ĐÁP ÁN: 2/3
#     sách:  V = a³/6         →  ĐÁP ÁN: 1/6
#     sách:  V = a³√2/3       →  ⛔ LOẠI BÀI (căn — ngoài ranh giới)
#
# Phép gán `a = 1` là chỗ DUY NHẤT bạn được phép tính, và `ingest` tự ghi nó
# vào `phep_chuyen` để người khác kiểm lại. Ba lỗi hay gặp và cách sửa:
#
#     "2a³/3"   → còn THAM SỐ   → gán a = 1, viết 2/3
#     "0.667"   → THẬP PHÂN     → viết phân số 2/3
#     "a³√2/3"  → CĂN THỨC      → bỏ bài, chọn bài khác
#
# ⚠️ NHÌN ĐÁP ÁN TRƯỚC KHI CHÉP ĐỀ. Căn có thể sinh ra TRONG LÚC GIẢI từ dữ
# kiện hoàn toàn sạch (trang 81 Câu 3: AB, AC, SB đều hữu tỉ → V = a³√2/3).
# Kiểm đáp án trước tiết kiệm được cả công chép đề.
