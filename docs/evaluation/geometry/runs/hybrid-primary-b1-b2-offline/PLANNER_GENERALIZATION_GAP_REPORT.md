# Planner generalization gaps

No Planner, Registry, Source Gate grammar, engine or kernel implementation changed in B1/B2. The service reuses them and makes their canonical V2 path consumable. No new served geometry family or independent generalization estimate is claimed.

The generic `_EffectResolver` composes typed effects/preconditions, recursive goal needs, existing bindings, memoization and cost-ranked candidate reuse. Section-specific `_dinh_cat_canh` and `_khoi_tren_thiet_dien` orchestrate pyramid/prism lateral cuts and derived pyramids; that is specialized reusable orchestration, not an unrestricted geometric theorem prover. Exact closure, intersection, metric, containment and volume checks validate planned results rather than discover arbitrary plans.

Bounds from current planner: 64 calls, 4 derived planes, effect depth 3, 32 needs, 8 candidates, 4 result lines, 8 result feet. Semantic IR remains 32 memory declarations, 50 statements and nesting depth 8. Historical hexagonal probes needing 33/36 declarations remain genuine refusals; no budget was raised.

Canonical V2 refuses curved solids, unsupported plane/premise/measurement forms, non-pyramid derived solids and unsupported qualified coordinate-frame identity even where the kernel or legacy Adapter /3 has related capability. Residual volume is not a fabricated residual mesh. Arbitrary topology, Boolean solids, arbitrary negation/conditionals and unsupported source grammar are not added by this service.

Current locked development replay repeats 22 served and 25 refusals with zero wrong-served/false-refused and the pre-existing one category mismatch. Omitted-goal/condition/negation and tampering tests add integration boundary evidence, not a new blind corpus. Source Gate remains a closed grammar with previously documented premise-coverage, anaphora and unsupported wording limits (Session 4A gap report and OPEN_ISSUES); quote membership alone is not semantic fidelity.

Next justified improvement requires an independently reproduced contract/source failure and a separate bounded experiment. Broad Planner rewrites, case-ID switches, new geometry families, oracle edits and higher IR limits are excluded.
