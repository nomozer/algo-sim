# Ownership preflight

Order: schema closed-field/shape/declaration validation -> ownership and qualified existence preflight -> capability translation -> Source Gate/legacy checks -> geometry.
All Bridge /1 and /2 consumers (Planner, Adapter /4, Adapter /3 shared gate) and curved Adapter /3 must execute it before capability refusal/fallback.
Retain source quotes and field presence. Resolve local labels under their own solid bindings; distinguish canonical identities of repeated local labels.
Constructed outputs inherit proven operand ownership in dependency order. Include /1 named and /2 stated section points and declared derived lineage.
An explicit or inferred scope never acquires foreign operands by global lookup. Qualified refs need both namespace and label ownership.
Derived highlight may reuse parent identities only through declared/verified derived topology, not an unrelated solid.
Capability refusal may trigger existing legacy fallback only after this preflight. Semantic refusal remains terminal.
Codes: UNKNOWN_SOLID_ID/UNKNOWN_VERTEX_REF/SOURCE_OBJECT_MISMATCH/AMBIGUOUS_REFERENCE, plus existing schema and relation codes.
