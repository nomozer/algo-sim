# Scope validation before bridge translation

PremiseSpec.solid_id is a typed scope, not an arbitrary _id string. Validate it explicitly before bridge translation discards the contextual field. Unknown scopes must raise UNKNOWN_SOLID_ID; incompatible operands must fail SOURCE_OBJECT_MISMATCH; ambiguous optional scope must fail AMBIGUOUS_REFERENCE. An absent optional scope remains accepted when the relation's ownership is unambiguous, without substituting a default for an invalid explicit value.

Reuse SolidSpec.local_vertices/canonical_vertex, parse_qualified_ref, and the existing typed argument-shape tables to identify actual vertex fields (not values or identifier fields). Compute a bounded ownership closure for explicitly constructed points from their producer operands; a premise's asserted scope cannot grant ownership to foreign operands. Stated section intersections inherit only their validated edge/target-solid ownership. A pre-existing vertex owned by a different solid cannot be renamed into a fresh point. Validate all explicit premise scopes, not just the two failing case IDs. Cross-solid relations belong to the contract's explicit relation representation and are not silently licensed by a single-solid premise scope.

Source Gate remains the authority for quote presence, exact relation binding, roles, negation and the source's geometric meaning. Preserve validated premise scope and quote in the bridge receipt so the proof is inspectable after conversion. Keep the planner's existing TypedFact schema and exact engine unchanged; introduce no parallel fact state or coordinate inference in the bridge.

Legacy aliases/non-root frames already refused by the bridge remain refused. Tests must distinguish explicit/absent/unknown/ambiguous scope, known-solid cross-contamination, constructed-point dependencies, shared labels and invalid source quotes. Mutants must show that removing validation or silently replacing foreign scope with a default reopens unsafe serves.

For original NEG20, do not weaken the locked reason list. Its target is the base plane of a nondegenerate prism and its claimed foot is a top vertex. A topology-based contradiction can be proved without placing the prism's unknown top coordinates. A separate fully placed exact metric witness must still reach the engine's actual projection-incidence/perpendicularity checks. No kernel or radical changes are permitted.
