## Independent exact oracle

For base A,B,C, n=(B−A)×(C−A), translation v shared by all corresponding vertices, and top point X=A+v+t(B−A),

`distance²(X, base) = (n·v)² / (n·n)`.

For a right prism this is `h²`, independent of the described top midpoint, translation, rotation, labels or base orientation. For an oblique prism the same expression uses the normal component of v; **never replace it with the squared lateral edge length**. A separate Fraction determinant/dot-product oracle should implement this formula without importing engine measurement helpers.
